# صندوق المقبرة والشادر — Netlify v3.0

هذه النسخة مخصصة للنشر على Netlify، وتستخدم:
- Netlify Identity لتسجيل المستخدمين وتحديد الأدوار.
- Netlify Functions للتحقق من المستخدم ومنع الكتابة غير المصرح بها.
- Netlify Blobs لتخزين الحالة المركزية للصندوق.
- تخزين محلي للعمل عند انقطاع الإنترنت.
- مزامنة دورية كل 5 ثوانٍ عند الاتصال.
- حماية من الكتابة فوق تعديل جهاز آخر باستخدام ETag/If-Match.

## 1) رفع المشروع
ارفع محتويات هذا المجلد إلى GitHub ثم اربط المستودع مع Netlify، أو ارفع المجلد مباشرة بالطريقة التي يوفرها Netlify.

## 2) تفعيل Identity
من Netlify:
Project configuration → Identity → Enable Identity.

لبرنامج صندوق خاص، يُفضّل اختيار Registration = Invite only، ثم دعوة المستخدمين من صفحة Identity → Users.

## 3) حساب المحاسب
أضف متغير بيئة في Netlify:
NETLIFY_OWNER_EMAIL = بريد المحاسب الرئيسي

ثم أعد النشر. عند تسجيل هذا البريد لأول مرة سيُسند له دور accountant بواسطة identity event function.

إذا كان الحساب موجودًا مسبقًا، افتح:
Identity → Users → المستخدم → Roles
وأضف الدور:
accountant
ثم سجّل خروج/دخول للمستخدم حتى يتجدد JWT.

## 4) الأعضاء
أنشئ أو ادعُ أعضاء من Identity. الحسابات الجديدة تكون member افتراضيًا.

العضو يستطيع القراءة والطباعة والتصدير، لكن لا يستطيع الكتابة إلى /api/state؛ التحقق من الدور يتم داخل Netlify Function.

## 5) البيانات
كل المستخدمين في نفس موقع Netlify يقرأون نفس حالة الصندوق المركزية.
عند كتابة محاسب من جهازين في الوقت نفسه، يستخدم الخادم ETag لمنع الكتابة فوق تعديل حديث؛ في حالة التعارض يتم جلب أحدث نسخة بدل دمج صامت غير آمن.

## 6) العملات
البرنامج يدعم:
- ليرة سورية SYP
- دولار أمريكي USD
- سعر صرف محفوظ لكل تحويل
- تحويل SYP → USD بالقسمة
- تحويل USD → SYP بالضرب
- تسجيل طرفي التحويل كسند صرف وسند قبض مرتبطين برقم عملية واحد

## 7) الطباعة وExcel
الطباعة عربية RTL، وملف Excel XLSX يُنشأ محليًا دون مكتبة خارجية.

## 8) PWA
يجب فتح البرنامج عبر HTTPS حتى يعمل Netlify Identity بأمان. بعد النشر يمكن تثبيته كتطبيق مستقل من المتصفح.

## 9) ملاحظة مهمة
وضع عدم الاتصال يعني استمرار العمل المحلي في الجهاز. المزامنة والحسابات المشتركة تحتاج اتصالًا بالإنترنت. لا يُسمح للعضو بالكتابة حتى لو حاول استدعاء Function مباشرة.
